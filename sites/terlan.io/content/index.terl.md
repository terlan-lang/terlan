Terlan is a statically typed programming language for building reliable,
concurrent applications without giving up direct native performance.

## Start with the language

Follow the [getting started guide](docs/getting-started/) to install the
compiler and run a first program, then explore the
[language guide](docs/language/).

## Built for systems that stay running

- Exhaustive types make invalid states visible during compilation.
- Lightweight actors isolate failures and support structured concurrency.
- Direct native compilation keeps deployment artifacts predictable.
- Typed HTML and static-site primitives power this documentation site.
